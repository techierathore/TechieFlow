| Small/cheap model for housekeeping | Not a user-facing concept (subagent/skill `model: haiku`). | `small_model` config (`core/v1/config/config.ts:77-79`) → title generation + project-copy only (`provider.ts:1909-1945`; `prompt.ts:216-221`). |

**Conclusion for routing:** per-phase model selection is **possible in both harnesses**, with the *command invocation* and the *subagent* as the two routing units. Neither harness lets a running agent change its own model for its own next step from inside the turn; the routing decision must be made at the harness boundary (which command/agent is invoked, with which declared model). See Adapter-Design.md §4.

## Where the two harnesses are **structurally different** (these drive the adapter)

1. **Hook mechanism.** Claude = shell commands wired in settings JSON with a stdin payload and exit-code protocol. OpenCode = in-process TS plugin functions with typed args; blocking = throw. Same *intent* (guard a tool call), different *shape* → a thin plugin that re-creates the Claude payload and shells out to the existing guard scripts is the smallest bridge (Adapter-Design §2).
2. **Context files.** Claude loads `CLAUDE.md`; OpenCode loads `AGENTS.md` and *ignores* `CLAUDE.md` when an `AGENTS.md` exists. Both can be pointed at the same content via `instructions` (OpenCode) and `@import` (Claude), but they are different files by default.
3. **Subagent naming and spawn.** Claude `Agent` tool with `subagent_type: general-purpose`; OpenCode `task` tool with `subagent_type: general`. The *model* the child runs on is declared on the agent definition in both.
4. **Command model scope.** Claude: turn-scoped (reverts on next prompt). OpenCode: written to the session row (TUI re-sends its own selection; SDK/`run -c` inherit). Neither is "per phase" for free — the phase must be the command.
5. **Token source.** Claude: transcript JSONL (undocumented shape but stable enough that the framework already parses it) or OTel; no hook carries usage. OpenCode: typed bus event + SQLite + `stats/export`, with real cost and per-child sessions.
6. **Bash guard.** Both parse compound commands natively (Claude per docs; OpenCode per tree-sitter source). The framework's belief that OpenCode prefix rules miss compounds is probably wrong — verify, then delete the workaround prose.
