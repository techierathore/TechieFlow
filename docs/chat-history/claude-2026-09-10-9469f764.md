## Why it's breaking

The file is on your disk but **was never committed**, so the CI checkout doesn't have it.

- `opencode.jsonc:921` points at `./.tfcore/tasks/create-project-brief.md`
- That file exists locally (`.tfcore/tasks/create-project-brief.md`, written Sep 8) but is **not in the git index**
- CI clones the repo, the file isn't there, the `{file:}` check fails

The mirror check passed in CI for the same reason — the `.claude/` copy is missing too, so both sides are consistently absent and the comparison sees nothing to compare.

**Root cause:** your `.gitignore` ignores `.tfcore/`, `.claude/` and `.opencode/` in this repo. Files added before those rules stay tracked and update fine (which is why the edited `opencode.jsonc` *did* get committed). But any **new** file under those folders is silently skipped by `git add` — no error, nothing in `git status`. So the pointer got committed and the file it points at did not.
