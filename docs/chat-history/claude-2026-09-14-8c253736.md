## Claude

I've written `~/opencode-export.sh`, which saves an OpenCode chat as a markdown file, the same way `claude-export.sh` does for Claude Code.

**The command** (run it from the project folder you used OpenCode in):

```
bash ~/opencode-export.sh
```

The options are the same as the Claude script:

| Command | What it does |
|---|---|
| `bash ~/opencode-export.sh` | Saves the newest chat to `docs/chat-history/opencode-<date>-<id>.md` |
| `bash ~/opencode-export.sh --list` | Lists this folder's chats with title, date and the last thing you said |
| `bash ~/opencode-export.sh --session <id>` | Saves an older chat, using an id from `--list` |
| `bash ~/opencode-export.sh myfile.md` | Saves to a file name you choose |

**How it differs from the Claude one:**
- OpenCode doesn't keep one file per chat. It keeps all chats in a single database, `~/.local/share/opencode/opencode.db`. The script only reads it and never changes it, so it's safe to run while OpenCode is open.
- OpenCode often leaves empty "New session" chats behind. If you don't give an id, the script skips those and saves the newest chat that actually has messages.
- Helper sessions that OpenCode starts on its own (subagents) aren't listed as separate chats.
- Like the Claude version, the file keeps your messages and the answers. It leaves out tool calls, the model's hidden reasoning, and text OpenCode adds for you, such as file reads and "continue" prompts.

**Tested on your real chats:**
- **Listing:** `--list` in TechieFlow showed its 7 OpenCode chats.
- **Newest chat:** in MyAiChats it saved the "JobChPlan folder contents overview" chat correctly.
- **Older chat:** `--session` on a longer TechieFlow chat saved 4 questions and 16 answers, in the right order.
- **Errors:** a wrong id, and a folder with no OpenCode history, both give a clear message.
- **Help:** `--help` printed one extra code line, which I fixed.
