## 2. Save-chat command

The Windows script wasn't on this Mac, so I rewrote it to match the steps in `docs/How-To-Save-A-Claude-Conversation.md`. I tested it on this conversation and the saved file came out correctly.

- **The script:** `~/.claude/claude-export.sh`. There's also a link to it at `~/claude-export.sh`, so the same `bash ~/claude-export.sh` you use on Windows works here.
- **A new `/save-chat` command:** `~/.claude/commands/save-chat.md`. It's global, so you can type it in Claude Code in any folder.

How to use it, from inside any Claude Code session:
```
/save-chat
```
or:
```
! bash ~/claude-export.sh
```

Either one saves the chat to `docs/chat-history/claude-<date>-<id>.md` in the folder you're in. If that folder has no `docs/` folder, it saves to `~/claude-session.md` instead. The options from the Windows version also work: `--list`, `--session <id>`, or a file path to save somewhere else. One difference from Windows: times in the file are shown in your Mac's local time.
