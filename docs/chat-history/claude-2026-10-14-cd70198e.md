## Claude

Neither. An alias is just a shorter name for a command typed in a terminal. It doesn't touch the window you're in and doesn't open another one. Typing `tfyolo` starts a new Claude Code session in the terminal where you type it, the same way typing `claude` does.

The steps would be:

1. In this session, type `/exit` (or press Ctrl+D). You're back at the terminal prompt in the same window.
2. Type `tfyolo`. Claude Code starts again in that window, in bypass mode, with YOLO switched on.

Plain `tfyolo` starts a fresh conversation, so you'd lose what's in the current one. I'd make `tfyolo -c` pick up the last conversation in that folder (`claude --continue`), so you keep the context and only the permission mode changes. If you'd rather keep the current session open, run `tfyolo` in a second terminal tab; the two sessions are independent.

Two things the alias would need:
- **One line in your shell profile:** `~/.bashrc` on WSL, `~/.zshrc` on the Mac. The framework would ship the command, and a one-time setup step adds the line on each machine.
- **YOLO switched on before Claude starts,** so the hook and the OpenCode change are in place from the first call.

Say go and I'll build `tfyolo` and `tfyolo -c` for WSL and the Mac, and test them in the scratch project first.
